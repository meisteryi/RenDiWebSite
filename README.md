# RENDI (렌디) 소개 웹사이트

스마트 렌터카 AI 보조 에이전트 **RENDI(렌디)**의 공식 서비스 소개 웹사이트입니다.

## 🎨 주요 디자인 사양
- **브랜드 메인 컬러**: 
  - Deep Navy: `#002c5f`
  - Pure White: `#FFFFFF`
- **인터랙션 스타일**: [Meisteryi Portfolio](https://meisteryi.github.io/YJH_Personal_Website/) 인터랙션을 계승하여, 메인 섹션에서 4대 핵심 키워드(로고 & 브랜드, 서비스 소개, 사업성, 차별성)를 클릭하면 하단에 상세 내용이 부드럽게 펼쳐지는 반응형 인터랙티브 구조로 구현되었습니다.

---

## 📂 4개 핵심 섹션 구성
1. **로고, 로고 설명, 이름 설명 (Brand Identity)**
   - **이름의 의미**: `RENT(렌터카)` + `BUDDY(버디)` = **RENDI**
   - 운전자의 곁에서 든든하게 길을 동행하고 안전 운행을 돕는 단짝 '버디(Buddy)' 같은 렌터카 AI 보조 에이전트
   - **로고 심볼**: 한국 렌터카 번호판 고유 기호인 **'하·허·호'의 자음 'ㅎ'**과 알파벳 **'R'**의 융합. 'R'의 동그란 루프와 상단의 두 개 바가 만나 한글 **'ㅎ'**을 완성하는 위트 있는 모빌리티 아이덴티티
   - **심미성 & 신뢰성**: 둥근 모서리(Squircle) 프레임과 Hyundai Navy `#002c5f` 컬러 시스템
2. **서비스 소개 (Service Overview & AAOS Implementation)**
   - **출발 전 비교 브리핑**: 평소 차량 유형(경차·세단·SUV·승합차·트럭·없음) 선택 시 더 뉴 아이오닉 5 기준 변속 다이얼·회생 제동 등 차이점 음성 브리핑
   - **온디바이스 호출어 "렌디"**: Vosk 한국어 소형 모델(0.22) + 문법 경량 그래프 + 고립 검사
   - **Pleos STT·TTS & 실시간 자막**: Pleos SpeechToText·TextToSpeech 3.3.1 기반 음성 대화 및 순정 내비게이션 오버레이 자막 표시
   - **Gemini 의도 분류 & 후속 대화**: 프록시 서버 기반 Gemini 의도 분류(키워드 규칙 폴백) 및 60초 대화 맥락 유지
   - **주행 상태별 안전 안내 & 재제안**: 기어 P·1km/h 이하만 정차로 판단, 주행 중 상세 안내는 보류 후 정차 시 먼저 재제안(30분 유지)
   - **공식 매뉴얼 검증 DB (v4.2.0)**: 현대차 공식 취급설명서 기반 5개 차종·237개 항목·66개 검증 오버레이 (미확인 항목 추측 방지)
   - **16:9 데모 영상 영역 & 실제 에뮬레이터 시연 시나리오 체험기** 탑재
3. **사업성 (Business Viability)**
   - **사회초년생의 차종 경험 기회**: 차를 바로 구매하기 부담스러운 사회초년생도 렌트를 통해 여러 차종을 운전해 보고 기능을 써볼 수 있음
   - **렌트 기간 동안 기능 직접 체험**: 궁금한 기능이 생겼을 때 렌디에게 물어보고 바로 사용해보며 조작법에 익숙해지고 나에게 편한 기능을 체감
   - **재렌트 및 미래 차량 구매 전환**: 조작법을 이미 아는 차종을 다시 고를 이유가 생기며, 나중에 내 차를 살 때도 직접 타보고 편하다고 느낀 차종을 구매 후보로 고려
4. **차별성 (Differentiation)**
   - **원래 타던 차 기준 차이점 설명**: 해당 차 단독 설명이 아닌, "원래 타던 차는 기어봉이었지만 이 차는 핸들 오른쪽 뒤에 변속 레버가 있어요"처럼 익숙한 기준에서 설명
   - **‘어디에 있는 어떻게 생긴 버튼’인지 설명**: "비상등 버튼을 누르세요"가 아닌, "가운데 화면 바로 아래에 있는 빨간 삼각형 표시 버튼을 누르세요"처럼 위치와 모양을 함께 안내
   - **상황만 말해도 원하는 기능 파악**: 기능 이름을 몰라도 "야, 창문에 김 서렸는데 어떡하냐?"처럼 겪는 상황을 그대로 말하면 원하는 기능을 파악해 안내

## 🚀 로컬 실행 방법

터미널에서 아래 명령어로 로컬 웹 서버를 실행하여 바로 확인할 수 있습니다:

```bash

python3 -m http.server 8080
```
